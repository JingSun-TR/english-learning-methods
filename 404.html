可理解输入假说
Comprehensible Input Hypothesis
★★★★★
通过接触大量略高于当前水平（i+1）的可理解语言材料，像婴儿学母语一样自然习得英语。不需要刻意背单词和语法。
听力 阅读 词汇 初级至高级
⏱ 每天至少1小时输入 查看详情 →
间隔重复系统
Spaced Repetition System (SRS)
★★★★★
利用艾宾浩斯遗忘曲线原理，在即将遗忘的临界点复习，用最少的时间实现永久记忆。Anki 是黄金标准工具。
词汇 初级至高级
⏱ 每天15-30分钟 查看详情 →
影子跟读法
Shadowing Technique
★★★★☆
像影子一样紧跟着原声模仿发音、语调和节奏，通过反复跟读训练口肌记忆和听力敏感度。
口语 听力 发音 中级
⏱ 每天10-15分钟 查看详情 →
泛读法
Extensive Reading
★★★★★
大量阅读自己能轻松理解（98%+）的英文材料，不求精读每个词，而是享受阅读过程，通过海量输入自然提升语感和词汇量。
阅读 词汇 写作 初级至高级
⏱ 每天20-30分钟 查看详情 →
沉浸式学习 / AJATT
Language Immersion / AJATT
★★★★☆
把自己完全浸泡在英语环境中——听英语、看英语、读英语、想英语。AJATT 的核心理念：让英语成为你生活的默认语言。
听力 阅读 口语 中级至高级
⏱ 尽可能多地接触英语，理想状态每天 3-5 小时 查看详情 →
Refold 方法
Refold Method
★★★★☆
AJATT 的现代化版本。分阶段系统学习：先大量输入建立语感，再逐步过渡到输出。强调「可理解性」而非盲目沉浸。
听力 阅读 口语 词汇 初级至高级
⏱ 每天1-3小时，持续1-2年 查看详情 →
句子挖矿法
Sentence Mining
★★★★☆
不从单词书学单词，而是从真实的语境中「挖」出句子。每个新词配一个真实例句，在语境中记忆。
词汇 阅读 语法 中级至高级
⏱ 每天20-30分钟（挖矿+复习） 查看详情 →
输出假说（强制输出）
Output Hypothesis (Pushed Output)
★★★★★
光输入不够，必须强迫自己开口说、动手写。只有当你尝试输出却发现说不出来时，大脑才会真正注意到差距并学习。
口语 写作 中级至高级
⏱ 每天15-30分钟 查看详情 →
TPRS 故事教学法
Teaching Proficiency through Reading and Storytelling (TPRS)
★★★★☆
通过有趣的故事和互动问答来学习语言。老师用简单的英语反复提问，学生用肢体和简短回答回应，在故事中自然习得。
听力 口语 词汇 初级至中级
⏱ 每次30-60分钟（课堂式学习） 查看详情 →
Pimsleur 音频法
Pimsleur Method
★★★★☆
通过精心设计的音频课程，利用「渐进式间隔回忆」原理，在对话中自然习得核心词汇和句型。不需要书本，只需听和回应。
口语 听力 发音 初级至中级
⏱ 每天30分钟 查看详情 →
Michel Thomas 方法
Michel Thomas Method
★★★☆☆
「无压力学习法」——不需要背诵、不需要作业、不需要记忆。老师引导你「发现」语言的规律，用你已知的词汇构建新句子。
口语 语法 词汇 初级至中级
⏱ 每节课60-90分钟，共约20小时 查看详情 →
Goldlist 金榜记忆法
The Goldlist Method
★★☆☆☆
用手写的方式将单词列表写下来，每两周「蒸馏」一次——记住的词剔除，没记住的重新写。利用大脑的潜意识长期记忆机制。
词汇 初级至高级
⏱ 每天20分钟（写列表），每两周10分钟（蒸馏） 查看详情 →
影子跟读 + 书写室
Shadowing + Scriptorium
★★★☆☆
将影子跟读和手写结合：先跟读，再逐字抄写，同时大声念出每个词。用多重感官强化语音、拼写和语法的联系。
写作 语法 发音 拼写 中级至高级
⏱ 每次10-15分钟 查看详情 →
流利永存法
Fluent Forever Method
★★★★★
用图像代替翻译来记忆单词（不用母语！），结合间隔重复系统，从第一天就开始练发音，建造你的「语言记忆宫殿」。
词汇 发音 语法 初级至中级
⏱ 每天30-45分钟 查看详情 →
LingQ 输入法
LingQ / Input-Based Learning
★★★★☆
通过阅读和听力输入「浸泡」语言，遇到生词一键保存，系统自动追踪你的已知词汇量，用真实的文章和播客代替教科书。
阅读 听力 词汇 初级至高级
⏱ 每天1-2小时 查看详情 →
Antimoon 方法
Antimoon Method
★★★☆☆
两个波兰人自学英语达到母语水平的方法总结：疯狂输入 + 用英语做你本来就喜欢做的事。拒绝课堂、拒绝语法书、拒绝背单词表。
听力 阅读 口语 初级至高级
⏱ 每天2-3小时 查看详情 →
FSI / 军方法
FSI / DLI Method (Military Language Training)
★★★★☆
美国外交学院（FSI）和国防语言学院（DLI）的全日制语言训练方法：高强度、结构化、以口语为核心目标。每天 5-6 小时，快速达到工作级流利度。
口语 听力 语法 各级别（但强度很大）
⏱ 每天3-5小时（高强度） 查看详情 →
i+1 最优难度理论
i+1 Theory (Optimal Difficulty)
★★★★★
选择难度刚好比你当前水平「高一点」的学习材料——太简单无聊，太难沮丧。i 代表你现有水平，+1 代表刚好能学会的新内容。
听力 阅读 词汇 初级至高级
⏱ 作为一种选择原则而非独立方法 查看详情 →
