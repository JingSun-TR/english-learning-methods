听力训练方法

专注于提升听力能力的学习方法

可理解输入假说
Comprehensible Input Hypothesis
★★★★★
通过接触大量略高于当前水平（i+1）的可理解语言材料，像婴儿学母语一样自然习得英语。不需要刻意背单词和语法。
听力 阅读 词汇 初级至高级
⏱ 每天至少1小时输入 查看详情 →
影子跟读法
Shadowing Technique
★★★★☆
像影子一样紧跟着原声模仿发音、语调和节奏，通过反复跟读训练口肌记忆和听力敏感度。
口语 听力 发音 中级
⏱ 每天10-15分钟 查看详情 →
沉浸式学习 / AJATT
Language Immersion / AJATT
★★★★☆
把自己完全浸泡在英语环境中——听英语、看英语、读英语、想英语。AJATT 的核心理念：让英语成为你生活的默认语言。
听力 阅读 口语 中级至高级
⏱ 尽可能多地接触英语，理想状态每天 3-5 小时 查看详情 →
Refold 方法
Refold Method
★★★★☆
AJATT 的现代化版本。分阶段系统学习：先大量输入建立语感，再逐步过渡到输出。强调「可理解性」而非盲目沉浸。
听力 阅读 口语 词汇 初级至高级
⏱ 每天1-3小时，持续1-2年 查看详情 →
TPRS 故事教学法
Teaching Proficiency through Reading and Storytelling (TPRS)
★★★★☆
通过有趣的故事和互动问答来学习语言。老师用简单的英语反复提问，学生用肢体和简短回答回应，在故事中自然习得。
听力 口语 词汇 初级至中级
⏱ 每次30-60分钟（课堂式学习） 查看详情 →
Pimsleur 音频法
Pimsleur Method
★★★★☆
通过精心设计的音频课程，利用「渐进式间隔回忆」原理，在对话中自然习得核心词汇和句型。不需要书本，只需听和回应。
口语 听力 发音 初级至中级
⏱ 每天30分钟 查看详情 →
LingQ 输入法
LingQ / Input-Based Learning
★★★★☆
通过阅读和听力输入「浸泡」语言，遇到生词一键保存，系统自动追踪你的已知词汇量，用真实的文章和播客代替教科书。
阅读 听力 词汇 初级至高级
⏱ 每天1-2小时 查看详情 →
Antimoon 方法
Antimoon Method
★★★☆☆
两个波兰人自学英语达到母语水平的方法总结：疯狂输入 + 用英语做你本来就喜欢做的事。拒绝课堂、拒绝语法书、拒绝背单词表。
听力 阅读 口语 初级至高级
⏱ 每天2-3小时 查看详情 →
FSI / 军方法
FSI / DLI Method (Military Language Training)
★★★★☆
美国外交学院（FSI）和国防语言学院（DLI）的全日制语言训练方法：高强度、结构化、以口语为核心目标。每天 5-6 小时，快速达到工作级流利度。
口语 听力 语法 各级别（但强度很大）
⏱ 每天3-5小时（高强度） 查看详情 →
i+1 最优难度理论
i+1 Theory (Optimal Difficulty)
★★★★★
选择难度刚好比你当前水平「高一点」的学习材料——太简单无聊，太难沮丧。i 代表你现有水平，+1 代表刚好能学会的新内容。
听力 阅读 词汇 初级至高级
⏱ 作为一种选择原则而非独立方法 查看详情 →
